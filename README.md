# Soul × 技能包专区 (SkillHub Soul Demo)

本项目是基于腾讯云 AI Skills 社区平台设计的 Soul × 技能包专区 交互原型演示。

##  设计思路 (Design Thinking)

本项目背景是在腾讯云现有的 SkillHub 开放平台上新增一个「Soul × 技能包专区」。目前平台已经沉淀了丰富的原子化技能（Skills），但部分用户仍面临“不知道怎么组合搭配”的困境。本专区的设计理念聚焦于以下四个维度：

**1. 范式跃迁：从“原子技能库”到“场景化员工中心”**
传统的技能社区往往呈现为一个干瘪的“工具黄页”，要求用户自身具备极强的 Prompt 编排与多 Agent 调度能力。本专区的设计思路是在现有平台上做加法：不封装新的 API，而是将平台已有的优质工具（SKILL）与特定的人设约束（SOUL）进行深度场景化打包。用户不再是零散地“挑工具”，而是“一键雇佣”一位自带特定技能组合的“新媒体运营专家”或“全栈架构师”，极大降低了非技术人员的认知负载。

**2. 白盒化信任构建 (Try-before-buy & White-boxing)**
AI 产品的核心痛点之一是执行逻辑的“黑盒化”。我在详情页引入了“沙箱演练终端”与“DAG 轨迹可视化”设计。用户在真实安装至工作台前，能直观看到该技能包拆解任务、调用底层 Skill 的全过程（如意图拆解 -> 检索 -> 校验）。这种“所见即所得”的试用体验，是打破顾虑、提升转化率的关键。

**3. “乐高式”的微调与二次创作闭环 (Soulcrafting)**
考虑到 B 端业务场景的非标属性，专区没有做一刀切的死板封装。基于 SkillHub 的开放特性，用户可以通过左侧的可视化面板一键 Fork 官方高分模板，灵活替换底层挂载的特定技能（Skills），并微调人设参数，零代码组装出适合自己企业私域数据的“专属员工”。

**4. 达尔文式的生态防腐机制 (Ecosystem Health)**
在 UI 展示层，我刻意摒弃了容易造假的“五星好评系统”，转而将平台系统级遥测数据前置——核心突出该技能包的**“工具调用成功率”**和**“平均执行耗时”**。配合上架前的动态沙箱防注入审核，用真实的工程数据来实现 SkillHub 生态内的良币驱逐劣币。

##  业务价值的深度思考 (Business Value Impact)

**1. 盘活现有生态资产，构建双边网络效应（Revitalizing Ecosystem）**
技能包专区的引入并不是凭空创造新工具，而是**极大盘活了 SkillHub 现有的存量资产**。通过引导优质创作者将 Prompt 工程经验与平台内已有的长尾 Skills 组装成“专家包”，不仅拉升了基础组件的调用率，更在平台内部建立起了“技能开发者（造轮子）”与“场景包创作者（搭积木）”互利共生的网络效应。

**2. 打通商业化变现的“最后一公里”（Monetization）**
对于社区开发者而言，单一的工具脚本往往难以定价；但将其按业务逻辑拼装成“能解决具体场景问题（如法务初审、简历筛选）的虚拟劳动力”后，便具备了清晰的商业溢价空间。专区为创作者指明了从“做工具”到“卖整体解决方案”的明确变现路径，也为平台未来探索基于复杂调用的商业抽成奠定了产品基础。

**3. 大幅降低门槛，拓宽平台客群边界（TAM Expansion）**
传统技术社区的受众往往局限于懂开发、会编排的硬核研发。该专区的出现将使用门槛降至极低，把平台的客群边界向外延展到了产品经理、市场运营、HR 甚至是传统中小企业主。非技术业务人员只需“一键安装”，直接帮助 SkillHub 撬动了更庞大的受众市场（Total Addressable Market）。

## 📸 功能模块与子页面介绍 (Features & Walkthrough)

### 1. 智能探索发现页 (Discover Dashboard)
这是用户进入专区的第一触点。
*   **AI 匹配助手**：顶部的胶囊搜索框不仅支持基础文本检索，更支持“一句话描述业务需求”的 AI 自然语言匹配。点击右侧发送按钮可展开平滑的悬浮多维筛选矩阵。
*   **生态货架展示**：下方按「官方精选」与「社区高分」分发卡片。卡片悬浮时带有轻微上浮与边缘蓝色泛光（Glow）的微交互，点击卡片即可无缝切入详情页。

> ![智能探索首页](./screenshots/首页1.png)



### 2. 技能包沉浸式详情页 (Bundle Details)
当选中如“全栈架构师”包时，进入此页。
*   **价值传递**：通过清晰的图文排版（搭配 Lucide Icon），直观罗列“它可以帮你做什么”以及“内含的底层工具链”。
*   **双规安装**：右侧卡片提供“工作台对话框安装（GUI）”与“CLI 命令行获取”两种方式，满足不同开发者习惯。

> ![技能包详情页](./screenshots/技能包详情.png)

### 3. Soulcraft 专属人格定制控制台 (Soul Configurator)
允许高级用户进行 Fork 与二次修改的控制面板。
*   **参数旋钮调优**：左侧提供三个核心滑块（沟通基调、护栏严格度、自主执行权限），用户可拖拽自定义。下方支持勾选或解绑非必需的底层技能树。
*   **底层逻辑实时同步**：所有的图形化操作，都会在右侧黑色的 Terminal 面板中，**实时映射并渲染为底层的 `SOUL.md` 代码配置**，兼顾小白的可视化与极客的代码透明度。

> ![人格定制控制台](./screenshots/fork.png)

### 4. Try-before-buy 沙箱演练模拟器 (Sandbox Terminal)
直观沙盒模拟促成用户转化。
*   **Mock Terminal**：左侧高度仿真的沙箱聊天终端，带有试用次数限制。
*   **多 Agent 协作工作流**：点击右侧的“预设演练场景（如：审查 PR）”后，终端内将以打字机与命令行结合的方式，输出多 Agent（规划者 -> 研究员 -> 编码员）的调度与日志流。
*   **DAG 执行轨迹溯源**：在日志流输出的同时，右下角的“DAG 轨迹面板”会同步高亮显示当前任务流转到了哪个节点，及其具体耗时，彻底打开 AI Agent 的执行黑盒。

## 🛠 本地运行指南

由于本项目为原生 HTML + 引入 CDN 资源开发，无任何复杂的构建步骤。

1. **环境要求**：任何现代浏览器（Chrome/Edge/Safari）。
2. **运行方式**：直接双击打开目录下的 `index.html` 即可完整体验上述所有交互与动画。
